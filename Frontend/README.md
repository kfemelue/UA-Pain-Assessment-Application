#  UA-PAIN-ASSESSMENT-FRONTEND

Requirements:
Node v25.8.1 or later

To run locally:

1. Clone the repository to your machine
1. `cd Frontend`
2. Create a .env file in the 'Frontend' folder based on .env.example or the text below, and fill in the server uri
```commandline
    server_base_uri =
    form_oid=
```
3. Run `npm install` in the terminal to install node dependencies
4. Run `npm run dev` to start the local server with Vite
5. Open a web browser and navigate to http://localhost:5173
